> **Inventario de filamento para talleres de impresión 3D** — Desarrollado por **TermuxX solutions**. Aplicación de escritorio moderna, visual y 100% offline para Windows. Gestiona tus bobinas en 3D interactivo, visualiza el nivel real de tus rollos, anticipa compras y sincroniza tus impresiones con Anycubic Slicer Next Gen.

Filoteca transforma las típicas hojas de cálculo aburridas en una estantería 3D interactiva para tu taller maker. Inspecciona tus rollos en 3D en tiempo real, aprecia los acabados reales del material (seda, mate, brillante, translúcido, glitter) y olvídate de quedarte sin filamento a mitad de una pieza.

## ✨ Características Principales

### 🎨 Bobinas 3D Interactivas y Realistas
- **Nivel Visual Real:** Aprecia de un vistazo cuánto filamento le queda a cada carrete directamente en el modelo 3D.
- **Acabados PBR Auténticos:** Calibrado para materiales mate, brillante, seda (brillo perlado), translúcido y glitter con colores fieles a la realidad.
- **Inspección Libre en 360°:** Gira, rota e interactúa con cada bobina desde cualquier ángulo antes de poner a imprimir.
- **Rápido y Ultraligero:** Animaciones fluidas optimizadas para no calentar tu PC ni consumir tu tarjeta gráfica mientras trabajas.

### 🤖 Companion Inteligente de Laminador
- **Detección Automática:** Filoteca lee en segundo plano tus trabajos laminados en Anycubic Slicer Next Gen, trayendo la vista previa en miniatura, el tiempo estimado y el peso de cada color.
- **Emparejamiento de Color:** Sugiere automáticamente la bobina más parecida de tu inventario para cada ranura.
- **Tú Tienes el Control:** Nunca descuenta material sin tu visto bueno. Confirma tus impresiones con un clic cuando terminen, evitando descontar filamento si la pieza falló o se canceló.

### 🛡️ Control Inteligente de Stock y Repuestos
- **Detección de Bobinas de Respaldo:** ¿Se está acabando un rollo? Filoteca detecta si ya tienes otro rollo nuevo sellado de la misma marca y color en tu taller, mostrándote una insignia de respaldo para que no te alarmes innecesariamente.
- **Semáforo de Reabastecimiento:** Alertas visuales claras (Crítico, Próximo, Preparado) para planificar tus compras con anticipación.
- **Lista de Compras Integrada:** Añade bobinas bajas en stock a tu lista de suministros en un solo clic.

### 🌍 Multi-Idioma y Moneda Local
- **Disponible en tu Idioma:** Soporte nativo completo para **Español** 🇨🇴, **English** 🇺🇸 y **Português** 🇧🇷.
- **Costes en tu Moneda:** Configura pesos colombianos (COP), dólares (USD), euros (EUR) o reales (BRL) para conocer el valor exacto por gramo de tus impresiones.
- **Modo Oscuro y Claro:** Estética cuidada de taller maker profesional inspirada en herramientas modernas.

### 🔒 100% Offline y Seguro
- **Privacidad Total:** Todos tus datos, inventarios, precios y notas se guardan únicamente en el disco de tu PC. Sin cuentas obligatorias, sin nube y sin requerir internet.

## 🚀 Descarga e Instalación Rápida

No es necesario compilar código ni instalar herramientas de desarrollo:

1. Ve a la pestaña de **[Releases](https://github.com/Mate1592/FILOTEK_ANYCUBIC/releases)** en este repositorio.
2. Descarga el archivo ejecutable portable: **`Filoteca-Portable-1.0.1.exe`**.
3. Haz doble clic sobre el archivo para iniciar Filoteca de inmediato. Puedes llevarlo en una memoria USB o dejarlo en tu carpeta de herramientas.

*(También tienes disponible el instalador clásico `Filoteca Setup 1.0.1.exe` si prefieres accesos directos en el Menú Inicio).*

## 🛠️ Desarrollo y Compilación Local

Si deseas contribuir o compilar el proyecto desde el código fuente:

```powershell
# 1. Instalar dependencias
npm install

# 2. Iniciar en modo desarrollo
npm run dev

# 3. Compilar versión portable de Windows (.exe)
npm run dist:portable
```
